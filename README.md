# Circuit Bloom — Power Plant Prototype

Godot 4.4.1 / GDScript / Mobile renderer. Android-first landscape prototype.

This branch explores Circuit Bloom as an industrial power-plant construction game rather than a motherboard. The background is generated artwork; the player-built machinery is currently drawn procedurally for fast iteration.

Core flow: **boiler → steam network → turbine → grid export**, with cooling, storage, cashflow, demand and output milestones layered on top.

See `POWER_PLANT_PROTOTYPE.md` for the prototype loop and controls.
